title: Video
overview: |
  Embeds YouTube, Vimeo, or a local video file. Local files load normally. Hosted players make no provider request until the visitor grants site-wide external-media permission; the contextual action grants that category for every video, map, and embed. YouTube mounts through `youtube-nocookie.com`, and revoking permission removes an existing hosted player.
