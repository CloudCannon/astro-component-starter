title: Video Modal
overview: 'A dialog overlay containing an embedded video that autoplays when opened and pauses when closed. Supports YouTube, Vimeo, and local video sources. The player floats on a dark backdrop with a close control above it, so the close is never under the embed. Open it from a button, or set `triggerStyle: poster` for a still frame with a play disc over it — the whole frame is clickable, which suits hero and feature media. Any Button or Card on the page can also open a video modal by setting its link to `^modal-{label}`, where `{label}` is the slugified modal label (e.g. `^modal-my-video`).'
