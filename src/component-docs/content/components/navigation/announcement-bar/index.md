title: 'Announcement Bar'
description: 'A dismissible site-wide announcement strip with an optional link.'
overview: 'Shows a short message above the main navigation on every page, driven by `src/data/announcementBar.json` (editable in CloudCannon under Data). Toggle it with `enabled`, and write the message in Markdown — add a link for an optional call to action. Closing it hides it for that visitor until the message changes — dismissal is stored against the message text, so publishing a new announcement brings the bar back for everyone.'
