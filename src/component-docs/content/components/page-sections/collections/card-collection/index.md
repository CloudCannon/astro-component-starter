title: Card Collection
overview: "Heading chrome around [Card Grid](/component-docs/components/building-blocks/wrappers/card-grid/) for curated cards — services, case studies, projects, resources, or blog-style tiles. Each card has an optional cover and a `contentSections` body, so a badge, date, author, or anything else is just another building block. Set `link` to make the tile clickable; a category badge (or any other nested link) stays its own target. Choose the Grid layout to crop every cover alike, or Masonry to keep each image's own shape. For posts that should update themselves, [Latest Posts](/component-docs/components/page-sections/collections/latest-posts/) queries the blog collection and feeds the same wrapper."
