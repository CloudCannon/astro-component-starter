title: Gallery Grid
overview: "An image grid with captions and a lightbox: click a tile to view the photo full size. The lightbox is the photograph — counter, close, arrows and caption sit inside its rectangle over a gradient scrim, on a near-opaque backdrop. Arrow keys and swipe step (wrapping at both ends), Escape or a backdrop click closes, and focus returns to the clicked tile. An optional thumbnail strip sits under the photo (`showThumbnails`). The Grid layout crops every tile alike (square or landscape); the Masonry layout keeps each photo's own shape and packs the columns shortest-first while preserving reading order — the same technique as the [Masonry](/component-docs/components/building-blocks/wrappers/masonry/) wrapper. The lightbox can be switched off for a purely decorative grid."
