title: Pricing Comparison
overview: 'A feature-by-feature comparison table across plans — the companion to [Pricing Tiers](/component-docs/components/page-sections/conversion/pricing-tiers/), which sells each plan as a card. Plans become columns (a highlighted plan gets the primary call to action), and each feature row holds one value per plan: type `yes` or `no` for a tick or a dash, or any text like "5 seats" to show it as written. Optional zebra striping is a single transparent gray on even rows only. Each plan can carry its own call to action in a final row. On small screens the table pans horizontally with the feature column pinned, the same treatment as the [Table](/component-docs/components/building-blocks/core-elements/table/) block.'
