title: Logo Cloud
overview: 'A "trusted by" strip of client logos, aligned by optical height so mixed aspect ratios sit on one line. Grayscale is on by default — logos mute to a single tone so a wall of brand marks doesn''t fight the page. A linked logo restores its color on hover in grayscale, or scales up slightly when the strip is already in full color. Unlinked logos stay still. Turn grayscale off for logos that must always show in full color. Switch on `scrolling` for a continuous marquee: it runs on the [Carousel](/component-docs/components/building-blocks/wrappers/carousel/) wrapper''s auto-scroll, and visitors who prefer reduced motion get a still strip instead.'
